# Buttonhole  

**Stick a prompt in it.**



---

I tried to find this.  

But instead, I got a hundred productivity startups doing spiritual cosplay with the copy/paste workflow — for $29/month.

"Is there a way to organize my own thoughts without signing up for a kombucha brand?" I wondered.

I came to paste a sentence, not unpack my *inner creative blocks*.  
(What the hell *is* an inner creative block?)

So here it is:  
**Buttonhole.**  
A button.  
That holds a prompt.

No cloud. No login. No telemetry.  
No integrations with tools I don't use.  
No onboarding video narrated by a guy named Lucas in a recycled sweater.

Just a side panel in VS Code.  
Click a prompt → it copies.  
Paste it where you need it. 
That's the whole feature set.

---

## What it does

- Shows a panel of buttons for your prompts
- Click = copied
- Add/edit/remove prompts in the UI
- Toggle them on/off
- Share your full deck with one click (you've done this before...)
- Stores everything in 1998 `prompts.json`

---

## What it doesn't do

- Sync to the cloud  
- Inspire you  
- Send a monthly usage digest  
- Recommend a new GPT for "enhanced synergy"  
- Ask you to pick a color palette for your "creativity zone"
- Oh dam, i did add that

## How to use it

1. `Ctrl+Alt+P` or run "Buttonhole: Open Prompt Panel"
2. Click a prompt
3. Paste it
4. Go back to doing actual work

**To install:**

- Download `buttonhole-1.0.0.vsix`  
- In VS Code: `Ctrl+Shift+P` → Install from VSIX → Done
